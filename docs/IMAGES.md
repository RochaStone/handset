# Images

Every image here is generated by `scripts/make-readme-images.py` from the fictional sample edition in `examples/`.
No photos, no real people, no real businesses. Juniper Vale, Port Halcyon and The Pocket Post are made up.

| File | What it is |
|---|---|
| `docs/img/hero-y2k.png` | the sample edition in the y2k-blog motif, used as the README hero |
| `docs/img/triptych.png` | the same edition in analog, cyberpunk and y2k-blog, side by side |
| `docs/img/step-01.svg` to `step-05.svg` | pixel step badges for "Start here" |
| `docs/img/divider.svg` | a gold pixel hairline between README sections |
| `docs/img/heart.svg` | the pixel heart beside "If it goes wrong" |
| `examples/handset.sample.html` | the sample edition as a finished page (cyberpunk, public twin, no gate) |

The pixel heart on the phone's start screen and the Snake heart are drawn by the page itself, in code.
